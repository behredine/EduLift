Student Guide — How a CPU Works

Use the simulator above as you read. Type or load an example program, then click Step to advance one pipeline stage at a time. Watch the diagram highlight which CPU component is active (Fetch → Decode → Execute).

1 · The fetch-decode-execute cycle

Every instruction a CPU runs goes through three stages:

Fetch: read the instruction from memory at address PC → store in IR → PC++
Decode: the Control Unit figures out what the instruction means
Execute: the ALU or Memory does the work (add, load, jump…)

2 · Registers

The PC (Program Counter) holds the address of the next instruction. The IR (Instruction Register) holds the instruction currently being decoded. R0–R7 are general-purpose registers — fast, tiny storage inside the CPU.

3 · Flags

After a CMP (compare) instruction the CPU sets flags: Z (zero — values were equal), N (negative — first value was smaller), C (carry — unsigned overflow). Conditional jumps (JE, JNE, JG…) read these flags to decide whether to branch.

4 · Memory

LOAD copies a value from memory into a register. STORE copies from a register into memory. Memory addresses are just numbers 0–127. Think of memory as a row of 128 tiny boxes, each holding one number.
